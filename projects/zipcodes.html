Home Price Explorer

A national interactive map of US housing values by ZIP code, 2000–2025.


This project began as a Wisconsin-only look at median home prices and has since grown to cover every ZIP code in the United States. It maps Zillow Home Value Index (ZHVI) data across a full 25 years, letting you watch how housing markets have shifted since 2000.

Features:
• Scrub the year slider or hit "Play Timeline" to animate median home values from 2000 through 2025
• Search any ZIP code to jump straight to it and see its current value
• Filter the view down to a single state, or explore the country as a whole
• Affordability filter — enter an annual income to highlight only the ZIP codes within reach
• Toggle the color scale between state and national normalization to compare locally or nationwide
• Live median, lowest, and highest value readouts that update with your selection
• Compare price history for up to three ZIP codes side by side in a generated line chart

Built with: Leaflet, vanilla JavaScript, and CARTO dark basemap tiles, using Zillow ZHVI data joined to ZIP Code Tabulation Area (ZCTA) boundaries from the U.S. Census Bureau.
